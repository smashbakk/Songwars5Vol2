Rules it was built under (all locked): each fighter chapter is 3 fights played AS that fighter; wins pay that fighter 1 upgrade point each (a cleared chapter = 3 points = one class jump); a fighter's chapter unlocks the moment you beat that fighter in the main story; Smash's chapter unlocks only after the finale frees him; each chapter's difficulty climbs inside itself (fight 1 low, fight 2 standard, fight 3 high); mirror matches are legal in every mode; each fighter's own signature track leads their chapter.

Drafting principles: every chapter tests three different problems (a style the fighter handles well, a style that pressures their weakness, a final exam); fights escalate inside the chapter; opponent appearances are balanced across the set (every fighter appears as an opponent 3 times, Rico Ruffino and LMSCURT 4, Smash once — in his own chapter's mirror finale).

Stats shorthand: HP / damage class / speed / minor mold.

## 1. Zayy Bizz (95 / Light / Fast / lunge) — the dart learns patience
1. **Rock Out Ali** (95 / Standard / Fast / projectile) — a same-band speed fight, but Ali zones from range: Zayy must close distance without eating projectiles.
2. **Rico Ruffino** (100 / Standard / Standard / multi-hit, Long reach) — the reach wall. Zayy's Short reach is the problem the whole fight asks about.
3. **Big Hood Tha King** (105 / Power / Slow / lunge) — the tank exam: Light damage vs 105 HP is a long fight against a fighter who ends it in three clean combos.

## 2. Rock Out Ali (95 / Standard / Fast / projectile) — keep them off the stage
1. **J.O NextLevel** (100 / Light / Fast / multi-hit) — a speed mirror in everything but damage: J.O pressures the zoning game with pure pace.
2. **Cin City** (100 / Standard / Fast / lunge + dog) — the dog does not respect zoning. Ali must manage two targets on one health bar.
3. **Loe Budda** (105 / Power / Slow / projectile) — the projectile duel against the heavier gun: same weapon class, 10 more HP, Power behind it.

## 3. J.O NextLevel (100 / Light / Fast / multi-hit) — speed meets its limits
1. **Zayy Bizz** (95 / Light / Fast / lunge) — the other Light/Fast: a pure pace mirror where the first mistake snowballs.
2. **LMSCURT** (95 / Power / Fast / multi-hit) — same speed, same mold, Power damage: everything J.O does, LMSCURT does harder per hit.
3. **Rico Ruffino** (100 / Standard / Standard / multi-hit, Long reach) — the reach exam again, from the other side: J.O's Standard reach must get inside Long and stay there.

## 4. Cin City (100 / Standard / Fast / lunge + dog) — two against the world
1. **LMSCURT** (95 / Power / Fast / multi-hit) — the interruption test: can the dog's pressure break up the roster's most violent close game?
2. **J.O NextLevel** (100 / Light / Fast / multi-hit) — the chase: J.O is fast enough to run from the dog and pick his spots; Cin City must corner him.
3. **Loe Budda** (105 / Power / Slow / projectile) — the wall: Power projectiles punish the dog's approaches, and 105 HP outlasts chip-and-run.

## 5. Rico Ruffino (100 / Standard / Standard / multi-hit, Long reach) — hold the range
1. **Bank Sinatra** (100 / Standard / Standard / projectile) — the mirror-band all-rounder, except Bank answers Long reach with a projectile: Rico must advance through fire.
2. **Zayy Bizz** (95 / Light / Fast / lunge) — the leak: Zayy is built to get inside reach. Rico's chapter turns on whether the wall holds.
3. **Loe Budda** (105 / Power / Slow / projectile) — the heavyweight: more health, Power damage, and a projectile of his own. Rico wins this on spacing or not at all.

## 6. Bank Sinatra (100 / Standard / Standard / projectile) — business is business
1. **Rock Out Ali** (95 / Standard / Fast / projectile) — the duel of the guns: Ali is faster, Bank is steadier; the projectile mirror at two speeds.
2. **Rico Ruffino** (100 / Standard / Standard / multi-hit, Long reach) — the range problem from the receiving end: Bank must cross Long reach to make his own game work.
3. **LMSCURT** (95 / Power / Fast / multi-hit) — the ambush exam: the lowest health in his path and the most dangerous fighter per second in the game. Bank's composure vs the glass cannon.

## 7. LMSCURT (95 / Power / Fast / multi-hit) — break everything first
1. **Zayy Bizz** (95 / Light / Fast / lunge) — the short-range duel: same band, same speed, opposite damage philosophies — LMSCURT's Power vs Zayy's patience.
2. **Cin City** (100 / Standard / Fast / lunge + dog) — the swarm: the dog interrupts the rushdown. LMSCURT must kill the pressure, not just the fighter.
3. **Big Hood Tha King** (105 / Power / Slow / lunge) — the burst exam: 105 HP and Power counters. Can the glass cannon end it before the King lands three clean looks?

## 8. Loe Budda (105 / Power / Slow / projectile) — the mountain moves slowly
1. **Bank Sinatra** (100 / Standard / Standard / projectile) — the measured duel: two projectile fighters, Budda heavier in every number.
2. **Big Hood Tha King** (105 / Power / Slow / lunge) — the other mountain: the roster's only 105-vs-105, Slow vs Slow, Power vs Power.
3. **J.O NextLevel** (100 / Light / Fast / multi-hit) — the catch exam: the fastest problem a Slow fighter can face. Budda's chapter ends by asking whether he can touch him at all.

## 9. Big Hood Tha King (105 / Power / Slow / lunge) — the crown is heavy
1. **Rock Out Ali** (95 / Standard / Fast / projectile) — the kite test: Ali's whole game is staying away from exactly this fighter.
2. **LMSCURT** (95 / Power / Fast / multi-hit) — the speed tax: Power that arrives twice as fast. Hood must trade, not chase.
3. **Cin City** (100 / Standard / Fast / lunge + dog) — the final exam: a two-body problem for the slowest fighter in the game, ending the chapter against pressure that never stops coming.

## 10. Tyshawn Smash (125 / Power / Fast / multi-hit, Long reach) — the freed guard
Unlocks only after the main-story finale frees him (locked rule). His chapter is the victory lap with teeth:
1. **Rico Ruffino** (100 / Standard / Standard / multi-hit, Long reach) — the first free fight: the gate's former measure of a challenger, now met as an equal.
2. **Bank Sinatra** (100 / Standard / Standard / projectile) — the man with the books: Bank's chapter knowledge of the tournament makes him the natural second door.
3. **Tyshawn Smash — MIRROR** — the bound guard himself: the copy the cause kept at the gate. Smash's chapter ends by fighting who he was, and the mirror rule the game already allows everywhere carries the story's biggest beat.
